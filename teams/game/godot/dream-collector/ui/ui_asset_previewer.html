XML 좌표 검증 — blueSheet.xml 기준

실제 blueSheet.xml 좌표와 Godot AtlasTexture Region 설정값을 비교합니다.

공통 실수 패턴

❌ 버튼이 찌그러지는 경우
TextureButton → StyleBoxTexture 미설정
NinePatch 대신 일반 texture_normal만 사용
→ 해결: theme_override_styles/normal에 StyleBoxTexture 등록
❌ 아이콘이 잘리는 경우
AtlasTexture region = Rect2(x, y, w, h)
x↔y 또는 w↔h 뒤바꿈 주의
→ blueSheet.xml의 x,y,width,height 순서 확인
⚠ 버튼 크기가 이상한 경우
TextureButton expand_mode = KEEP_SIZE 시 최소 크기 고정
→ custom_minimum_size로 명시 설정 권장
✓ 올바른 NinePatch 설정 예시
var stb = StyleBoxTexture.new()
stb.texture = atlas
stb.texture_margin_left = 15
stb.texture_margin_right = 15
stb.texture_margin_top = 15
stb.texture_margin_bottom = 15
button.add_theme_stylebox_override("normal", stb)
